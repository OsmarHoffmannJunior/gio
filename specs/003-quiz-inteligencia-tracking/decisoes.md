# Decisões em aberto: quiz, inteligência e tracking (003)

Rev. 1c, 21/11/2026 (respostas do Osmar às 09h42 em `respostas-osmar-2026-11-21.md`; 13 de 16 resolvidas). Numeração própria (D1 a D16 desta spec). Recomendações são propostas; não são parecer jurídico. Custos e limites com fonte em `pesquisa.md`.

| # | Decisão | Opções | Recomendação | Situação |
|---|---|---|---|---|
| D1 | Quiz anônimo ou só logado | Anônimo / Só logado | Anônimo para responder; conta para salvar e receber ofertas (menos atrito, mais respostas) | Resolvida (Osmar, 21/11 09h42): quiz da fase 1 aprovado conforme a recomendação |
| D2 | Perguntas permitidas na fase 1 | Só estética e preferência / Incluir tipo de pele e fototipo / Incluir saúde | Só estética e preferência. Fototipo e tipo de pele são úteis para laser, mas podem ser lidos como dado de saúde; deixar para a fase da anamnese com RIPD | Resolvida: só perguntas de estética e preferência, sem dados de saúde |
| D3 | Unidade cria quiz | Não / Só duplicando modelo, com aprovação / Livre | Só duplicando modelo, com aprovação, e só se liberada (padrão bloqueado) | Resolvida: unidade só a partir de modelo, com aprovação e se liberada |
| D4 | Incentivo para responder | Nenhum / Benefício igual para todos com regulamento / Sorteio | Nenhum na fase 1; se houver, benefício igual para todos com regulamento (CDC). Sorteio exige autorização específica e não é recomendado | Resolvida: sem incentivo por enquanto |
| D5 | Arquitetura de tracking | A só GTM web / B sGTM Cloud Run (cerca de R$ 530,00 por mês) / C Stape (R$ 0 até 10 mil req.; R$ 117,78 no Pro) / D Zaraz (1 milhão de eventos grátis; exige site na Cloudflare) / E coletor próprio + envio server-side | **E**, com GTM web enxuto só para page_view e Consent Mode. B, C ou D só se a Gio quiser muitas tags de terceiros sem desenvolvimento | Resolvida: E, coletor próprio no nosso domínio com validação, deduplicação, gravação no nosso banco e envio pelo servidor (GA4, Meta, TikTok, Google Ads) |
| D6 | Onde guardar eventos | Só GA4 / Banco próprio / Banco próprio + warehouse | Banco próprio (Postgres da 001) + arquivo em Parquet (R2, 10 GB grátis) + export GA4 para BigQuery (sandbox grátis, 1 milhão de eventos por dia) como segunda fonte | Resolvida (Osmar 21/11 10h14) |
| D7 | Estrutura do GA4 | Uma propriedade por marca com dimensão de unidade / Uma por unidade / 360 com subpropriedades | Uma por marca (Gio e Sorridents separadas) com `unidade_id`; GA4 próprio da unidade opcional como destino extra; 360 só se a Gio quiser pagar por permissão por unidade dentro do GA4 (preço do 360: não coletado) | Resolvida: Analytics da rede, uma propriedade por marca com a unidade como dimensão. Com domínio próprio, a rede recebe acesso ao Analytics e ao Search Console da unidade (requisito do provisionamento do domínio) |
| D8 | Banner de consentimento | Próprio / CMP comercial / CMP grátis de código aberto | Próprio ou de código aberto, seguindo o guia da ANPD e o Consent Mode v2; CMP certificada não é exigida no Brasil | Resolvida (Osmar 21/11 10h14) |
| D9 | Nomenclatura dos eventos | Inglês (padrão GA4) / pt-BR `objeto_acao` | pt-BR `objeto_acao` no particípio (continua a 001 e fica legível para a Gio), com mapeamento para os eventos recomendados de cada destino | Resolvida (Osmar 21/11 10h14); renomeação `objeto_acao` já aplicada na spec 001 (rev. 3.2) |
| D10 | Clima e UV | INMET + normais (grátis) / Open-Meteo comercial (preço não encontrado) / Ambos | INMET + normais na fase 4; Open-Meteo só se a previsão e o UV diários virarem campanha automática, depois de cotar a licença | Resolvida: INMET e normais; fontes pagas desligadas por enquanto |
| D11 | Concorrência local | Não coletar / Places API (paga; 1.000 grátis por mês no SKU Enterprise, depois US$ 20 por mil) / Levantamento manual trimestral | Manual trimestral até haver verba; regra "sem serviços pagos" vale agora | Resolvida: fontes pagas desligadas; levantamento manual |
| D12 | Google Trends | Pedir acesso à API alpha / Exportação manual / Ambos | Ambos: pedir a API (sem garantia de prazo) e começar com exportação manual mensal por UF | Resolvida: Trends por exportação manual |
| D13 | Retenção de eventos brutos | 13 meses / 25 meses / 5 anos | 25 meses quentes e arquivo frio agregado depois; evento com `cliente_hash` segue a retenção do cliente (002) | Resolvida: 25 meses de eventos brutos |
| D14 | Ferramenta de análise de produto | Nenhuma / PostHog (1 milhão de eventos grátis, servidores fora do Brasil) / Própria | Nenhuma na fase 1; painéis próprios. PostHog só com avaliação de transferência internacional (LGPD art. 33) | Resolvida: nenhuma ferramenta paga na fase 1; painéis próprios |
| D15 | Dono do tracking | R-SEO / Agência / Pessoa nomeada na Gio | Pessoa nomeada na Gio com R-SEO, apoiada pela agência; quem implementa não aprova a própria mudança | Resolvida: uma pessoa nomeada na Gio |
